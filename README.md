# BLOOP AI 🤖

Чат с двумя нейросетями в тёмном веб-интерфейсе:

| Режим | Что это | Что умеет |
|---|---|---|
| **Мощная модель** | Большая языковая модель (z-ai CLI или любой OpenAI-совместимый API) | Отвечает на любые вопросы, знает науки, пишет код и тексты, **память диалога**, **поиск в интернете** с источниками, **генерация картинок**, **понимание изображений** |
| **Моя нейросеть** | Мини-GPT (трансформер), **обученный с нуля** в этом проекте | Сам генерирует русский текст символ за символом в стиле научной энциклопедии — видно, как нейросеть «пишет» изнутри |

> Важно быть честным с ожиданиями: мини-модель весит ~1,9 млн параметров (у больших моделей — сотни миллиардов). Она не знает фактов и не отвечает на вопросы — она обучена предсказывать следующий символ по тексту энциклопедии, поэтому выдаёт похожий на энциклопедию текст. Всё «всезнающее» делает мощная модель.

## Возможности

- 💬 Чат с памятью диалога (история чатов хранится в браузере)
- 🔍 Поиск в интернете с ответом на основе источников (кнопка-переключатель «Поиск в интернете»)
- 🎨 Генерация картинок по описанию (переключатель «Рисовать»)
- 🖼 Понимание изображений (кнопка 📎 — прикрепи картинку и спроси)
- 🧠 Режим «Моя нейросеть» — генерация собственной мини-GPT без интернета
- 📱 Адаптивный интерфейс + PWA-манифест: на телефоне «Добавить на главный экран»

## Быстрый старт

Нужны: **Node.js 18+**, **Python 3.10+** и pip.

```bash
# 1. PyTorch для мини-модели (CPU-версии достаточно)
pip install torch --index-url https://download.pytorch.org/whl/cpu

# 2. Запустить сервер
node server.js        # или ./start.sh — он сам поставит PyTorch

# 3. Открыть http://localhost:3000
```

Если в репозитории уже есть `checkpoints/mini_gpt.pt` — мини-модель работает сразу.
Если нет — обучи свою (см. ниже).

## Обучить свою мини-модель с нуля

```bash
# 1. Собрать корпус русских научно-энциклопедических статей (~4 МБ, Wikipedia)
python3 python/build_corpus.py

# 2. Обучить (~20–30 минут на обычном CPU, ~7 минут на игровой видеокарте)
python3 python/train.py --corpus data/corpus.txt --steps 2600

# 3. Проверить генерацию руками
python3 python/infer.py --prompt "Квантовая механика —" --max-new 300
```

Параметры модели по умолчанию: 4 слоя трансформера, 4 головы внимания,
размерность 192, контекст 192 символа, словарь ~250 символов (символьная
токенизация — каждый символ это токен). Архитектура та же, что у GPT:
каузальное многоголовое внимание, MLP-блоки, residual-связи, LayerNorm,
сэмплирование с temperature/top-k.

## Мощная модель: два варианта подключения

Сервер сам выбирает, что доступно:

1. **z-ai CLI** (если установлен в системе) — используется по умолчанию:
   чат, поиск (`web_search`), генерация и понимание картинок.
2. **OpenAI-совместимый API** через переменные окружения:

```bash
export OPENAI_API_KEY=sk-...
export OPENAI_BASE_URL=https://api.openai.com/v1   # или свой прокси/локальная модель
export OPENAI_MODEL=gpt-4o-mini
node server.js
```

Без одного из этих бэкендов работает только режим «Моя нейросеть».

## API сервера

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/api/chat` | `{mode:"pro"|"mini", message, history[], search?}` | `{text, sources}` |
| POST | `/api/image` | `{prompt, size?}` | `{url}` — PNG в `/generated/` |
| POST | `/api/vision` | `{question, image:"data:..."} ` или `{imageUrl}` | `{text}` |

## Структура проекта

```
bloop-ai/
├── server.js               # HTTP-сервер (Node, без зависимостей)
├── public/index.html       # весь фронтенд: тёмная тема, чаты, настройки
├── python/
│   ├── minigpt.py          # токенизатор + GPT-архитектура на PyTorch
│   ├── train.py            # обучение
│   ├── infer.py            # генерация (используется сервером)
│   └── build_corpus.py     # сбор корпуса с Wikipedia
├── data/corpus.txt         # обучающий корпус
├── checkpoints/mini_gpt.pt # обученная модель
├── docs/APK_EXE.md         # как превратить проект в APK и EXE
└── start.sh                # запуск одной командой
```
